# infinity-security-notes# Security Notes

My personal cybersecurity study notes, organized by tool and topic. Built while learning toward **SOC analysis**, **DevSecOps**, and **ethical hacking**, with each topic documented as I learn it.

## Repository Structure

```
security-notes/
├── README.md
└── nmap/
    ├── README.md
    └── nmap-notes.md
```

## How to use this repo

1. Open a topic folder.
2. Read its `README.md` for an overview.
3. Open the notes file for the details, commands, and cheat sheets.

## Adding a new topic

```bash
mkdir tool-name
touch tool-name/README.md tool-name/tool-name-notes.md
```

Then add the folder to the table above.
